# Connect SillyTavern

Use these settings to configure SillyTavern as a Client for your gateway.

## Key setup

**Status:** documented
**Checked:** 2026-10-13

### Settings

- **Custom Endpoint (Base URL):** `https://<your gateway>/openai/v1`
- **Custom API Key:** `<your key>`
- **Enter a Model ID:** `<model name>`

### Steps

1. Open API Connections (the plug icon).
2. Set API to Chat Completion and Chat Completion Source to Custom (OpenAI-compatible).
3. Fill in these fields, then choose Connect.

Source: [SillyTavern's own documentation](<https://docs.sillytavern.app/usage/api-connections/openai/>)
