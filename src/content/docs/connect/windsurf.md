# Connect Windsurf (Cascade)

Use these settings to configure Windsurf (Cascade) as a Client for your gateway.

## MCP setup

**Status:** unverified
**Checked:** 2026-10-13

**Authentication:** Sign in or use a Key.

### Settings

- **Server URL:** `https://<your gateway>/mcp`

### Steps

1. Add a server with "serverUrl": "https://<your gateway>/mcp" to the MCP configuration.
2. Sign in when asked, or add an Authorization header with your key.

> Note: The documentation does not say which sign-in method Windsurf uses.

Source: [Windsurf (Cascade)'s own documentation](<https://docs.devin.ai/desktop/cascade/mcp>)
